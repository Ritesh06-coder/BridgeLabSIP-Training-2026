# BridgeLab SIP Training 2026

Collection of Java practice exercises for BridgeLab SIP Training.

Getting started

- Compile a file:
```bash
javac core-java-practice/gcr-codebase/programming-elements/KmtoMilesfixed.java
```
- Run a compiled class (from its package root):
```bash
java core-java-practice.gcr-codebase.programming-elements.KmtoMilesfixed
```
